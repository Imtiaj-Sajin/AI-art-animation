## 1. How the project started

- The user saw a YouTube tutorial ("Claude Opus 5.5 + JavaScript = INSANE 2D Animations", channel
  RandomAI, https://www.youtube.com/watch?v=MPDhk385gSg) and asked whether Claude could make similar
  art-based animations. The video itself couldn't be watched (no transcript). Write-ups of the technique
  describe: draw scenes in code (Canvas, SVG or p5.js) with a timeline and easing, render frames in a
  headless browser, and stitch them with FFmpeg.
- The user shared screenshots from that video: colored-pencil dinosaurs, a paper-cut "what" collage,
  ink library, watercolor tree, and so on. Analysis: the "real" look comes from **line boil** (redrawing
  outlines every 2–3 frames), crayon/pencil hatching, paper texture, torn-paper collage, layered
  watercolor and handwritten text.
- **Test piece:** `seed-to-tree/` (16 s, a seed grows into a tree through the seasons). The user liked
  it but said **"need to be more creative"**.

## 5. Problems found and fixed (so they aren't repeated)

| Problem | Fix |
|---|---|
| Paper grain looked like TV snow on dark scenes | Sparser grain texture; color layer erased at 0.85 |
| Sea and wave lines showed through ships, rocks, walls | `HD.occlude()` erases ink under foreground shapes |
| Washes ended in visible edges when the camera zoomed out | Extend background washes well past the frame |
| Text cut off by camera push-ins (e.g. 1:24 "the light is out.") | Draw such captions in screen space (`c.setTransform(1,0,0,1,0,0)`) |
| Overlapping labels (keeper names, thumbnail words) | Wider spacing, smaller size; always check stills |
| The wave looked like a blob | Rebuilt as a curling breaker with lip, face highlight, flow lines, foam claws |
| Crash spray looked like cotton clouds | Smaller, more transparent washes plus more spray dots (still a little soft; could improve) |
| Voice had a big-room echo | Removed the reverb; added `tools/voicefx.py` studio chain |
| Static drone music | Per-scene `music` cues: chord pad, piano, heartbeat pulse; ~13 dB under the voice |
| `np.convolve` on full-length audio hung for 10+ minutes | Cumulative-sum moving average / FFT convolution |
| `-(x) ** 2` JS syntax error | Parenthesize: `-((x) ** 2)` |
